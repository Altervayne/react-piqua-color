# Preview images

The root README references two screenshots from here:

- `preview-light.png` — the picker in light mode
- `preview-dark.png` — the picker in dark mode (toggle "Dark" in the demo)

To (re)generate them, run the demo (`npm run demo`) or open the
[live demo](https://altervayne.github.io/react-piqua-color/), screenshot the
picker panel, and save the two PNGs here with those exact names. ~320px wide reads
well in the README. Only these images live here; nothing in this folder is
published to npm (`files` ships `dist` only).
